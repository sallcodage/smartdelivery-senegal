MISE À JOUR : PAGE D'ACCUEIL PUBLIQUE + LOGO UNIQUE
====================================================

INSTALLATION
1. Décompressez ce fichier.
2. Copiez le dossier « smartdelivery » par-dessus votre projet
   (Windows : acceptez « Remplacer les fichiers dans la destination »).
3. Dans un terminal, dans le dossier frontend :
     npm test          → 30 tests réussis attendus
     npm run dev       → ouvrir http://localhost:5173/
4. Si tout est bon :
     git add .
     git commit -m "Page d'accueil publique et logo unifié"
     git push
   Render redéploie automatiquement le site.
